WEB UNTUK KAMU — PETUNJUK SINGKAT

STRUKTUR
- index.html       : isi halaman dan teks surat
- style.css        : desain, animasi, dan tampilan HP
- script.js        : navigasi halaman dan musik
- audio/lagu.mp3   : lagu latar milikmu
- video/kenangan.mp4 : video untuk halaman ketiga
- images/video-poster.svg : gambar sebelum video diputar

CARA MEMAKAI
1. Ekstrak ZIP ini.
2. Masukkan lagu ke folder audio dan beri nama persis: lagu.mp3
3. Masukkan video ke folder video dan beri nama persis: kenangan.mp4
4. Buka index.html di browser untuk mencoba.
5. Untuk dibagikan lewat internet, unggah seluruh isi folder ke GitHub Pages atau layanan hosting statis.

CATATAN MUSIK
Musik mulai saat tombol “Buka pesan ini” ditekan. Browser modern biasanya memblokir suara otomatis sebelum interaksi pertama, jadi ini cara paling andal untuk memastikan musik bisa menyala.

KUSTOMISASI
- Ubah tulisan surat di index.html, pada bagian HALAMAN 2.
- Ubah ucapan penutup di bagian HALAMAN 4.
- Pastikan nama file audio/video sama persis dengan yang ditulis di HTML.
